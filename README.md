# RustHub

Клиент-серверное сетевое приложение на языке **Rust** для выполнения заданий № 3, 4 и 5 по дисциплине «Компьютерные сети» (**Async TCP / Tokio**, **TCP vs UDP**, **IP Multicast**).

## Реализованные задания

1. **Задание № 3 — Асинхронный сервер (`127.0.0.1:7878`, Tokio):**
   - Асинхронные сокеты (`tokio::net::TcpListener`, `tokio::spawn`) без блокировки основного потока.
   - Параллельное обслуживание множества клиентов, команда `/slow <сек>` для демонстрации неблокирующей работы, рассылка `/broadcast`, замер RTT по `/ping`.
   - Корректная обработка штатного (`/quit`) и внезапного обрыва клиента без падения сервера.
   - Встроенная кнопка **«Автотест 3 клиентов»** в GUI.

2. **Задание № 4 — Сравнение TCP и UDP (`TCP :7878` vs `UDP :7879`):**
   - Последовательная отправка пачки сообщений (100 / 500 / 1000 шт.) и файла (1 МБ или 25 МБ) по TCP и UDP.
   - Автоматический замер времени передачи (мс), скорости (сообщ/с и МБ/с) и процента потерь пакетов с выводом сводной таблицы.

3. **Задание № 5 — Multicast-приложение (`239.0.0.1:7880`):**
   - Multicast-сервер рассылает периодические оповещения `«Сервер обновлен»` каждые 5 секунд (и по кнопке внепланового вызова).
   - Multicast-клиент подписывается на группу (`SO_REUSEADDR` + `join_multicast_v4`), принимает оповещения сервера и поддерживает групповой чат между несколькими одновременно запущенными окнами клиента.

## Запуск

1. Запустите сервер: `cd RustHub-Server && cargo run` (или `run-server.bat`).
2. Запустите один или несколько клиентов: `cd RustHub-Client && cargo run` (или `run-client.bat`).
3. Переключайтесь между вкладками **«Задание 3: Async TCP»**, **«Задание 4: TCP vs UDP»** и **«Задание 5: Multicast»**.
